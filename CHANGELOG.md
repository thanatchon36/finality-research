## [0.1.0] - 2026-11-08

### Added
- Attacker model (`finality.attacker`): rational-choice venue selection and an exact log-gap decomposition;
  transaction finality explains 67% of the payoff gap between a bank core and a cross-chain bridge.
- Loss-distribution Monte Carlo (`finality.lda`): Poisson frequency, log-normal body, a planted Pareto tail and
  cascades, so every tail estimate can be checked against a known truth, plus a second-order compound-sum
  correction from incident-level to annual-aggregate return levels.
- Peaks-over-threshold inference (`finality.evt`): GPD maximum likelihood with delta-method, parametric-bootstrap
  and profile-likelihood intervals for return levels.
- Coverage study (`finality.coverage`, `run_study.py`): 1,000 records per design cell from master seed 20261108,
  with every interval of every record cached in `results/cache/` so the study is resumable and auditable.
- Interbank contagion (`finality.contagion`): network generator, linear DebtRank, spectral stability and systemic
  ranking. The generator is a bit-exact port of the web instrument's random number generator.
- Preprint *False Confidence in the Tail* (`paper/paper.pdf`) in arXiv layout. Every number enters the text as a
  macro generated by `paper/analysis.py`, and `paper/make_figures.py` checks each figure for overlapping text.
  `make arxiv` writes the source archive with the `.bbl` included.
- Web reader of the paper (`docs/paper/`, built by `make web`) and FINALITY, the interactive browser instrument
  (`docs/instrument/`), both served by GitHub Pages.
- Dataset on Hugging Face, [`thanatchon36/finality-research`](https://huggingface.co/datasets/thanatchon36/finality-research)
  (CC BY 4.0), built by `make hf`: all 36,000 interval estimates of the coverage study scored against the truth,
  200,000 simulated years of losses, the true return-level curve, the two single records, the attacker venues and the
  interbank network with its cascades. `scripts/export_hf.py` regenerates every file from the seeds and checks it
  against `results/results.json`.
- 19 unit tests and CI on every push.
